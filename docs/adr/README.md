# Architecture Decision Records

Расхождения с [baseline](../baseline/Sasha_Memory_OS_Technical_Roadmap_and_Spec_RU.md) и ключевые архитектурные выборы фиксируются здесь.

## Именование

`ADR-NNN-short-title.md` — трёхзначный номер, kebab-case в заголовке файла.

Пример: `ADR-001-canonical-memory.md`
